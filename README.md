# Hobi dan Aktivitas Saya

Website sederhana yang dibuat menggunakan HTML dan CSS untuk menampilkan informasi tentang diri saya, website favorit, hobi, dan target belajar. Project ini dibuat sebagai latihan dasar Web Development untuk memahami struktur HTML dan penggunaan CSS dalam mengatur tampilan website.

## Tech Stack

- HTML5 — digunakan untuk membuat struktur halaman website.
- CSS3 — digunakan untuk mengatur warna, ukuran teks, tata letak, border, dan tampilan website.

## Cara Menjalankan

1. Clone repository ini ke komputer:

   ```bash
   git clone https://github.com/USERNAME/hobi-dan-aktivitas-saya.git
   ```

2. Masuk ke folder project:

   ```bash
   cd hobi-dan-aktivitas-saya
   ```

3. Buka file `hobi.html` menggunakan browser.

4. Website akan ditampilkan di browser dan dapat digunakan untuk melihat halaman Hobi dan Aktivitas Saya.
